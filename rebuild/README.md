# Beast King 新生版 — Phase 1 / Foundation

本ブランチは公開中の main と既存の保存データを変更しない再構築用です。旧アプリの画面やCSSを読み込まず、画面・操作・ローカルプロフィールを新規実装します。第一弾の既存カードデータ、個別イラスト、戦闘エンジン、抽選処理、ソロシナリオは互換性のため共有します。

## 起動

リポジトリをこのブランチに切り替え、ルートで `python3 -m http.server 8000` を実行し、`http://localhost:8000/rebuild/` を開いてください。直接ファイルを開くのではなくHTTPサーバーを使用します。

## 実装範囲

- 初回だけの名前・プロフィール設定（独立保存キー）、スターター4種類
- 第一弾1,152枚の図鑑・検索・カード詳細、6段階のレアリティ演出
- 32＋4のデッキ編集、所持枚数と同名2枚上限、4スターター選択
- 12枚入りパック、秘宝、重複変換
- 全20戦のソロと3段階の練習戦、既存ルールでのCPU戦、合成素材選択、戦績と報酬
- 新デザインの固定画面レイアウト。端末サイズによるページ分割

## 未実装・未検証

- 第二弾1,152枚とカードアートの新規制作、𠮷良原デッキ
- サーバー認証、運営機能、マルチ、ランク、端末同期、既存アカウントからの移行
- BGM、対戦中断の永続化、画面の実機検証、全カードの新規イラスト制作
- 戦闘エンジンそのものの再設計。現段階は既存エンジンを共有する基礎版

秘密の運営コードを公開クライアントに埋め込まないこと。第二弾カードは一般ユーザーもパック入手できるようにし、運営専用の完成デッキ配布のみサーバー側で権限確認する。
