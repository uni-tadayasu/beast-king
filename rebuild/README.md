# Beast King 新生版 — Phase 2 / Expansion foundation

本ブランチは公開中の main と既存の保存データを変更しない再構築用です。旧アプリの画面やCSSを読み込まず、画面・操作・ローカルプロフィールを新規実装します。第一弾の既存カードデータと個別イラスト、ソロシナリオを継承し、戦闘エンジンと抽選処理は再構築用の独立モジュールに分離しています。

## 起動

リポジトリをこのブランチに切り替え、ルートで `python3 -m http.server 8000` を実行し、`http://localhost:8000/rebuild/` を開いてください。直接ファイルを開くのではなくHTTPサーバーを使用します。

## 実装範囲

- 初回だけの名前・プロフィール設定（独立保存キー）、スターター4種類
- 第一弾・第二弾合計2,304枚の図鑑・検索・カード詳細、6段階のレアリティ演出
- 32＋4のデッキ編集、所持枚数と同名2枚上限、4スターター選択
- 各1,152枚の第一弾・第二弾パック、12枚入り、秘宝、重複変換
- 全20戦のソロと3段階の練習戦、既存ルールでのCPU戦、合成素材選択、戦績と報酬
- 新デザインの固定画面レイアウト。端末サイズによるページ分割

## 未実装・未検証

- 第二弾1,152枚の新規イラスト、運営専用レガリアの別イラスト制作・実ファイル登録、𠮷良原デッキの認証付き配布
- サーバー認証、運営機能、マルチ、ランク、端末同期、既存アカウントからの移行
- BGM、対戦中断の永続化、画面の実機検証、全カードの新規イラスト制作
- 戦闘エンジンそのものの再設計。現段階は既存エンジンを共有する基礎版

### 運営専用レガリア
通常版 B1024 は第二弾パックに含まれます。別イラスト版 OP-B1024 は同名・同性能で、一般収録2,304枚とは別の限定印刷です。両パック抽選、通常所持カードの付与、公開図鑑、一般ローカル保存から除外しています。同名2枚制限は通常版と限定版を合算します。専用イラストは `assets/rebuild/operator-regalia.webp` に登録予定で、現時点では画像制作前です。
`operator-deck.js` は第一弾20枚＋第二弾16枚（限定レガリア2枚を含む）からなる𠮷良原デッキのサーバー統合用構成です。カード配布やアカウント変更は行いません。秘密の運営コードは公開クライアントに埋め込まず、実際の配布・対戦許可は今後認証済みサーバーに接続して実施します。
