# Beast King 新生版 — Phase 6 / Cloud backup

新生版を従来版と共存させ、main の /rebuild/ に先行公開する構成です。既存の保存データを変更しません。旧アプリの画面やCSSを読み込まず、画面・操作・ローカルプロフィールを新規実装します。第一弾の既存カードデータと個別イラスト、ソロシナリオを継承し、戦闘エンジンと抽選処理は再構築用の独立モジュールに分離しています。

## 起動

公開時のURLは https://www.beast-king.com/rebuild/ です。ローカルではリポジトリのルートで `python3 -m http.server 8000` を実行し、`http://localhost:8000/rebuild/` を開いてください。直接ファイルを開くのではなくHTTPサーバーを使用します。

## 実装範囲

- 初回だけの名前・プロフィール設定（独立保存キー）、スターター4種類
- 第一弾・第二弾合計2,304枚の図鑑・検索・カード詳細、6段階のレアリティ演出
- 32＋4のデッキ編集、所持枚数と同名2枚上限、4スターター選択
- 各1,152枚の第一弾・第二弾パック、12枚入り、秘宝、重複変換
- 全20戦のソロと3段階の練習戦、既存ルールでのCPU戦、合成素材選択、戦績と報酬
- 新デザインの固定画面レイアウト、端末サイズによるページ分割、統一した独自アイコン・カード枠・ソロ決闘場の背景、縦横比を保つアート表示、ゾーン一覧。
- 新生版のサイト概要、canonical/OGP、各種ファビコン、独立したホーム画面用マニフェスト。未完成ページは noindex とし、従来版のSEOと混在させない。
- 承認済みの個別WebPを登録するアートマニフェストと重複ファイル検査。レガリアの元画像は変更禁止。
- 独立したD1保存テーブル、アカウント認証付きクラウド保存・復元、リビジョン競合検出、復元前ローカルコピー。王庭から手動で利用し、従来版の端末連携を使用する。サーバーの配備とマイグレーション適用が必要。
- ソロ戦の各操作後にローカル保存。ブラウザを閉じても再開でき、結果報酬を重複付与しない。運営デッキの再開はサーバーで認証する。
- 既存の3曲（メニュー、通常戦、危機時）を独立したBGMコントローラーで再生。どちらかのHPが2,500以下なら危機BGM。音量とON/OFFを保存し、非表示タブでは停止。

### レガリアと運営専用𠮷良原デッキ
第一弾 B0512 と第二弾 B1024 のレガリアは従来の通常イラスト `assets/design-v2/cards/individual/king.webp` を共通使用します。両方とも一般入手可能です。別イラスト版 OP-B1024 は廃止し、有効なカードIDから除外しました。同名2枚制限は収録弾を問わず合算します。専用の𠮷良原デッキの利用権のみ運営認証が必要です。一般プレイヤーは所持カードから同じ構成を組むことができます。
`operator-deck.js` は第一弾20枚＋第二弾16枚（通常版レガリア2枚を含む）からなる𠮷良原デッキのサーバー統合用構成です。サーバーの `/api/rebuild/operator-deck` に GET（利用権復元）と POST（初回専用コード照合）を実装しました。既存の運営アカウント認証を必須とし、環境変数 `BK_OPERATOR_REGALIA_CODE` のみで照合します。D1 の監査テーブルに利用権を一回だけ記録し、端末連携後も同じアカウントで復元します。公開クライアントに秘密のコードや権限フラグを保存しません。運営アカウントの既存セッションが必要です。API配備後はロゴを7回押し、初回だけ専用コードを入力し、𠮷良原デッキを選択できます。ソロ開始ごとにサーバー照合します。ソロ戦闘自体はクライアント実行であり改変耐性はありません。マルチ・ランクは新カタログ対応のサーバー戦闘と権限検証の接続が必要です。
