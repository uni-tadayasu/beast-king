# ビーストキング｜BEAST KING

第一弾 **「六源の覚醒（ろくげんのかくせい）」**、第二弾 **「王源の継承」**、第三弾 **「継承の共鳴」**、第四弾 **「星界の創世」**、第五弾 **「幻彩の夢界」**。第一弾1,157枚・第二〜第四弾各1,156枚・第五弾96枚、合計4,721枚のカードを集め、メインデッキ32枚と特殊デッキ4枚で戦うオリジナルブラウザカードゲームです。全10章・各章2回戦（全20戦）のソロモード、32構築の覇王CPUへ挑むイベント戦、コードを共有する1対1のオンラインルーム、リアルタイムのランクマッチに対応しています。PC・スマートフォン・タブレットとも、画面内に収まる横長のゲーム画面でプレイします。

**公開先:** https://www.beast-king.com/

**新生版の保存データ:** https://www.beast-king.com/rebuild/ — 以前の先行版で遊んだデータを独立保存のまま利用できます。公開トップページは全5弾・4スターター・各モードを統合した正式な入口です。先行版の収録は従来の2,304枚のままで、本編のカードIDやセーブデータとは別管理です。

## はじめかたと4つのモード

初回にプレイヤー名を1〜16文字で設定し、山・川・種・草・花・木・王の7つのプロフィールアイコンから選びます。名前とアイコンはこのブラウザに保存し、あとから変更できます。トップメニューで開始すると、ソロ・イベント戦・マルチ・ランクを選べます。プレイヤー名はオンライン対戦で相手に表示する名前にも使います。

| モード | 対戦の内容 |
| --- | --- |
| ソロ | 全10章×2回戦＝20戦。進行を保存し、クリア済みの回戦は再戦可能。3段階の自由な練習戦も用意 |
| イベント戦 | 32種類の環境構築に自分の所持デッキで挑む覇王CPU戦。採用カード確認・中断・再開に対応 |
| マルチ | ルームコードを共有する1対1のオンライン対戦 |
| ランク | オンラインで相手を探し、結果をレートへ反映。60秒見つからない場合はBOT戦 |

## 画面・お知らせ・効果ログ

トップメニュー、通常メニュー、デッキ工房、各モードの準備画面に専用デザインを用意しています。対戦フィールドはソロ「古代樹の闘域」、イベント戦「星冠の試練場」、マルチ「星鏡の双陣」、ランク「黄金の王座」です。ランクのBOT戦もランク用フィールドを使います。

サイト最上部には右から左へ流れる最新情報を表示します。一時停止・再開でき、「最新情報」から全文を読めます。アニメーションを減らす設定にも従います。リリース情報は `news.js` の `NEWS_ITEMS`、最新のメッセージはサーバーの公開お知らせから読み込みます。

自分の手札のカード名・コスト・効果全文を左パネルで確認できます。手札の選択は相手へ送信せず、相手ターン中も読むことができます。

カード効果・攻撃・回復・消滅・合成・ターン進行を、バトル右側の効果ログへ記録します。履歴は新しい順に直近1,000件を保持します。小さい画面では「効果ログ」ボタンから右側のパネルを開きます。相手の未発動ギミックや非公開の手札はログにも表示しません。

スマホ・タブレットを縦に持って開いた場合も、ゲーム画面を仮想的に90度回転して横長の配置を維持します。開始操作では対応ブラウザへ全画面と横向き固定を要求し、未対応の環境でも仮想横画面でプレイできます。OSそのものの回転ロックや全画面許可をWebサイトが強制変更することはありません。ホーム画面への追加用マニフェストも横向きを指定しています。

| 系統 | 追加効果の条件 |
| --- | --- |

### 王冠竜レガリア・プレミアム

公開構築例 `regalia-premium-v1` は、王冠竜レガリアと専用カード17種類を各2枚採用した、メイン32枚＋特殊4枚のデッキです。レガリア本体を強化し、サーチ・召喚補助・守護・回復・再展開・専用合成で支える構成です。新17枚は通常魔獣7種・ミラクル6種・ギミック2種・合成魔獣2種です。

新カードのパック配属は、固定シードのシャッフルにより第一弾5種、他の3弾各4種へ割り振っています。開封のたびに所属パックを変える仕組みではなく、図鑑に示す収録弾から全員が同じ条件で入手できます。レガリア本体は引き続き第二弾です。18種類ともGGRで、通常パックのレアリティ排出率・価格・保証は変わりません。

ショップの全5パックから構築例と不足枚数を確認できます。必要な36枚をすべて所持した場合だけ保存枠へ読み込め、構築例の閲覧・読み込み・初回開始による一括無料配布はありません。カード性能と使用条件は全プレイヤーで共通です。運営専用なのは認証済み完成構築枠とレガリアの専用スキンで、一般プレイヤーも収集した同じカードを通常デッキで使用できます。

初回は4種類から選んだ1種類（36枚）のみ無料で受け取ります。既存の所持カードは削除せず、未所持のスターターは自動配布・復元・読み込みしません。各スターターは魔獣16枚・ミラクル8枚・ギミック8枚のメイン32枚と、対応する合成魔獣4枚の合計36枚です。ミラクル8枚には「合成」を2枚含みます。4種類とも秘宝ショップで固定36枚セットを各300秘宝で購入できます。必要枚数を全て所持すると編成可能になります。所持上限を超えるカードは1枚5秘宝へ変換し、すべて上限に達した商品は追加購入できません。購入は所持カードのみ更新し、現在のデッキや初期配布分を変更しません。その他のカードはパックから集めます。

全4,721枚に有効な画像を割り当てます。セルヴァ8派生はユーザー指定による同一原画の共有例外で、固有の表示画像は4,714点です。カード名・効果・数値はHTMLで重ね、レアリティごとの箔・光沢・虹色の反射を維持します。王冠竜レガリア（B0512）の通常の公開絵と、認証済み運営枠だけの専用スキンは区別します。

レアリティは、**ノーマル → レア → キラレア → キラキラレア → ギラレア → ギラギラレア** の6段階です。ギラギラレアが最高位です。

## 基本ルール

- メインデッキは32枚ちょうど、特殊デッキは4枚ちょうど。合計36枚で対戦します。この枚数を満たさないデッキでは対戦できません。同じカードは各デッキに2枚までで、所持枚数も超えられません。
- メインデッキには通常の魔獣・ミラクル・ギミックを入れます。特殊デッキには合成魔獣だけを入れ、特殊ゾーンに置きます。
- お互いのハートポイントは5,000から開始。攻撃などで0になると敗北し、相手のハートポイントを0にすると勝利します。回復の上限も5,000です。
- 魔獣の攻撃力・守備力、戦闘ダメージ・回復・結界は100単位で表示します。カードの枚数やエーテルのコストは別の単位です。
- 自分のターン開始時にエーテルが最大値まで回復します。先攻の最大値は1→2→3→4…、後攻は最初の2ターンだけ通常より1多く、2→3→3→4…と増えます。どちらも上限は10です。この後攻補正は新規対戦に適用し、補正導入前の中断・進行中の対戦は元の増加順を維持します。
- 出場ゾーンは通常の魔獣と合成魔獣を合わせて4体まで。ギミックは2枚まで場に出せます。
- 初期手札は4枚。手札の上限も4枚で、自分のターン開始時に4枚になるまで補充します。カード効果によるドローも4枚で止まり、上限により引けないカードは山札に残ります。
- 通常の魔獣と合成魔獣は、召喚した次の自分のターンから1ターンに1回攻撃できます。「速攻」は召喚したターンから攻撃可能です。
- 「守護」を持つ敵がいる場合、攻撃では守護を先に狙います。
- 魔獣への攻撃は下記のモデル比較で判定し、通常の戦闘では反撃しません。「吸収」は戦闘で相手のハートポイントを実際に減らした分、自分のハートポイントを回復します。
- ミラクルは即時発動。ギミックは設置後、条件を満たすと自動発動します。反射カードは攻撃元へダメージを返し、魔獣サポートカードは次の自分のターンに味方全体の攻撃力・守備力を強化したり、守備力を回復したりします。
- 山札が空の状態でドローすると、回数に応じて増える疲労ダメージを受けます。

3枚入りの旧カスタムデッキを読み込む場合は、超過分を所持カードで補って32枚＋4枚と2枚上限に合わせます。所持カードそのものは減らしません。

## モデルと配置

通常魔獣のモデルは「アタック型」「ディフェンス型」です。合成魔獣はすべて、両方を兼ねる「アタック・ディフェンス型」です。魔獣・ミラクル・ギミックは、すべてまっすぐ縦向きに置きます。前は相手へ向かう方向、後ろは自分側です。

| カードの種類・モデル | 基準枠に対する配置 |
| --- | --- |
| 通常魔獣・アタック型 | 枠より少し前（相手側） |
| 通常魔獣・ディフェンス型 | 枠より少し後ろ（自分側） |
| 合成魔獣・アタック・ディフェンス型 | 枠の中央にぴったり合わせる |
| ミラクル | 枠より少し左 |
| ギミック | 枠より少し右 |

ミラクルは使用後にお墓ゾーンへ移動します。左寄せの表示枠には「直前の発動」を表示し、そこからカードを再使用することはできません。ギミックは右寄せで、2枚まで設置できます。

通常魔獣のアタック型が攻撃を受けると、守備力にかかわらず必ず消滅し、お墓ゾーンへ移動します。持ち主は、攻撃した魔獣の攻撃力全額をハートポイントへのダメージとして受けます。

通常魔獣のディフェンス型と合成魔獣は、現在の守備力と相手の攻撃力を比較します。守備力が相手の攻撃力以上なら、魔獣は生存し、守備力も持ち主のハートポイントも減りません。同値も生存・ダメージ0です。相手の攻撃力が守備力を上回る場合は消滅し、持ち主は超過分だけハートポイントが減ります。

| 攻撃を受ける魔獣 | 相手の攻撃力 | 自分の守備力 | 結果 |
| --- | ---: | ---: | --- |
| 通常アタック型 | 800 | 1,000 | 消滅・持ち主に800ダメージ |
| 通常ディフェンス型・合成魔獣 | 800 | 1,000 | 生存・ダメージ0・守備力は1,000のまま |
| 通常ディフェンス型・合成魔獣 | 800 | 800 | 生存・ダメージ0・守備力は800のまま |
| 通常ディフェンス型・合成魔獣 | 1,000 | 800 | 消滅・持ち主に200ダメージ |

通常魔獣・合成魔獣とも、通常の戦闘では反撃しません。魔獣への攻撃で持ち主が受けるダメージは、結界を消費せず、そのままハートポイントから差し引きます。ハートポイントへの通常の直接攻撃には結界が適用されます。

合成魔獣は攻撃するときに攻撃力を使い、攻撃されたときは守備力で受けます。守備力が相手の攻撃力以上なら生存して守備力・持ち主のハートポイントとも減らず、下回る場合は消滅して持ち主が超過分だけ受けます。ミラクルや反射などのカード効果は守備力を減らすことがあり、守備力が0になると消滅します。再生カードや魔獣サポートカードで回復する場合は、最大守備力を超えません。

## 合成召喚

1. 再生カードに属するミラクル「合成」（M0256、コスト3）を使い、特殊ゾーンの特殊デッキから召喚したい合成魔獣を1体選びます。
2. 自分の手持ち（手札）・出場ゾーン・お墓ゾーンの魔獣カードを、1枚以上選びます。手持ちのみ・出場ゾーンのみ・お墓ゾーンのみでも合成でき、複数のゾーンを混ぜてもかまいません。通常の魔獣も合成魔獣も素材に使えます。素材の指定枚数に上限はありません。レガリア専用合成魔獣を選ぶ場合は、素材もレガリアと専用魔獣に限定されます。各カード本文の素材条件に従います。
3. 選んだ素材をすべて異世界ゾーンへ送り、合成魔獣を出場ゾーンに召喚します。異世界ゾーンへ送った素材はその対戦中に再利用できません。「合成」のカード自体はお墓ゾーンへ送ります。
4. 素材2枚目以降は、1枚につき合成魔獣の攻撃力・守備力をそれぞれ+100します。消費するエーテルは「合成」の3だけです。

| 素材の枚数 | 攻撃力・守備力への加算 |
| --- | --- |
| 1枚 | 基礎値のまま |
| 2枚 | それぞれ+100 |
| 5枚 | それぞれ+400 |

素材にできるのは自分の通常の魔獣と合成魔獣です。異世界ゾーンへ送ったカードは再利用できません。出場ゾーンが4体で埋まっている場合でも、出場中の魔獣を素材にして召喚する場所を空けられます。召喚前の選択画面でキャンセルした場合は、カードやエーテルを消費しません。

専用ミラクル「王冠竜の神合」など、別の合成カードには固有のコスト・召喚先・素材条件があります。上記の3エーテルは通常の「合成」（M0256）の値です。カード詳細と選択画面に表示する条件を優先します。

ゲーム紹介と詳細ルールは `about.html` にも掲載しています。

## ソロ・イベント戦・マルチ・ランクの対戦

ソロの章モードは全10章、各章2回戦の20戦です。勝利で次の戦いが解放され、敗北・引き分け・降参では同じ回戦から再挑戦できます。クリア済みの回戦は再戦でき、進行はバックアップにも含まれます。自由な練習戦ではCPUの「見習い」「策士」「覇王」を選べます。マルチではルームコードを共有して1対1で対戦し、ランクではオンラインの対戦相手を探します。ランクマッチで60秒たっても対戦相手が見つからない場合は、BOTとの対戦を開始します。BOTの相手は画面に明示します。

オンライン対戦は1手番120秒です。時間切れは敗北になります。画面を閉じたり別の画面へ移動したりしても、オンライン対戦は一時停止されません。ランクマッチのレートはサーバーで管理し、コードを使うルーム対戦ではレートを変更しません。

CPU対戦もオンライン対戦も、メイン32枚＋特殊4枚、開始時5,000ハートポイント、初期・最大手札4枚の共通ルールで戦います。

## 端末連携・クラウド保存・バックアップ

開始後はプレイヤーごとのクラウド保存に接続します。名前とアイコン、所持カード、秘宝、通常デッキ・特殊デッキ、編集中のデッキ、ソロの章進行と中断状態、戦績、設定を保存します。オンラインのレートと対戦状態はサーバーで管理します。

設定の「端末連携と同期」で、元の端末から連携コードを発行し、別の端末へ入力します。コードは10分間有効で1回だけ使用できます。連携後は端末ごとに独立した認証情報を発行し、同じプレイヤーの保存・レート・プレゼント受取履歴を共有します。端末を連携すると、その端末の手元データは連携先の保存に置き換わり、異なるアカウント同士のデータは合成しません。

変更は自動保存し、表示中は15秒ごとにも最新の保存を確認します。通信できない間は端末に保存します。別端末でも更新されていた場合は上書きせず、設定で使用するデータを選択してください。対戦中に別端末のデータを勝手に読み込むことはありません。

「お知らせ・プレゼント」からシステムメッセージ、プレゼント、公開イベントを確認できます。報酬はプレイヤーごとに1回だけ受け取れ、複数端末でも重複しません。同じカードの4枚目以降は通常のパックと同じく5秘宝へ変換します。

ゲームのJSONバックアップには、認証情報・連携コード・サーバー上のレートは含めません。同じプレイヤーとしての引き継ぎには端末連携を利用してください。サイトデータを消去した端末は、接続できる別の連携端末から再度コードを発行して接続できます。

## BGM

画面・対戦種別・ハートポイントに合わせて、次の4曲を切り替えます。

| 使用する場面 | 提供された音源 | 配置先 |
| --- | --- | --- |
| メニュー・カード一覧・デッキ編集など | `00001.mp3` | `assets/audio/menu.mp3` |
| ソロ・ルーム・ランクの通常バトル | `00002.mp3` | `assets/audio/battle.mp3` |
| 環境デッキ戦の通常バトル | イベント戦用の提供音源 | `assets/audio/battle-event.mp3` |
| どちらかのHPが2,500以下のバトル | `カードゲームBGM.mp3` | `assets/audio/battle-danger.mp3` |

ソロ・イベント戦・マルチ・ランクのすべてで、自分か相手のハートポイントが半分の2,500以下になるとクライマックス用のBGMへ切り替わります。2,500ちょうども対象です。両者が2,500を超えるまで回復すると、イベント戦はイベント専用曲、それ以外は通常バトル曲へ戻ります。対戦画面から離れるとメニュー曲です。曲が変わっても音量設定を引き継ぎ、二重再生しません。

BGMは初期設定でオン・音量50%です。ゲーム画面の音楽操作でオン・オフと音量を変更でき、設定はこのブラウザに保存されます。各曲はループ再生し、画面の切り替えでは前の曲を止め、切り替え先の曲を前回の位置から再開します。

ブラウザが許可していれば画面を開いたときに再生し、自動再生が制限される場合は最初のクリック・タップ後に再生を開始します。別のタブを開くなどしてゲームのタブが非表示になると一時停止し、戻ると再開を試みます。ブラウザの許可が必要な場合は、次のクリック・タップで再試行します。

## 運営の配信・イベント・メンテナンス

認証済みの運営はゲームのロゴを7回続けて押すと運営管理を開けます。一般プレイヤーに運営権限は付与されず、各操作はサーバーでも権限を確認します。

- システムメール・プレゼント・イベント・公開お知らせは、一覧から新規作成、下書き保存、編集、複製、予約公開、終了を行えます。日時は日本時間で入力し、公開状態はサーバーの時刻で切り替わります。
- メール・プレゼント・イベントは、全プレイヤーまたは指定プレイヤーへ配信できます。プレゼントとイベントには秘宝および最大12種類のカードを指定できます。公開開始後は配信先と報酬を固定し、別の内容は複製から新たに作成します。
- 「既読」「受取」では実際に開いた・受け取ったアカウントの履歴を確認できます。同じ報酬はアカウントごとに1回だけ受け取れ、連携した複数端末でも重複しません。所持上限を超えたカードの秘宝変換も受取内容に表示します。
- メンテナンスは即時または開始・終了日時で予約できます。有効期間は新しい対戦の受付を止め、進行中の対戦と待機のキャンセルは継続できます。公開メッセージと次回の予定をゲーム内に表示します。
- プレイヤーは上部の「お知らせ・プレゼント」、または設定の「データとプロフィール」→「受取ボックス」からメール・プレゼント・イベントを確認します。

## 運営専用構築の𠮷良原デッキ

本編の最新構築はrevision 4のプレミアムデッキです。メイン32枚＋特殊4枚で、第二弾所属の王冠竜レガリア（既存ID B0512）と新17種類を各2枚採用します。18種類はすべてGGRで、カード性能は一般プレイヤーと共通です。運営認証後のコード確認により構築済みデッキの利用権を付与し、ソロ・環境デッキ戦・ルーム・ランクに共通ルールで使用できます。レガリアを含む収録カード自体は一般プレイヤーもパックから入手できます。運営専用イラストは追加カードではなく、利用権のあるアカウントにだけサーバーから配信するスキンです。秘密のコードは公開ソースに含めず、サーバー設定で管理します。

revision 1・2・3の利用権がある運営は、再コード入力なしでrevision 4へ更新できます。不足カードだけを一度付与し、所持カード・秘宝・専用画像・通常のデッキを保持します。構築を使うと運営枠が更新され、空き枠があれば直前の構築を「旧」として保存します。対戦測定は本番の覇王CPUで先攻・後攻を入れ替えて実施し、敗北・引き分け・未決着を勝利に含めません。全勝を保証する仕様ではありません。構築と測定条件は [運営デッキの検証記録](docs/OPERATOR-DECK.md) を参照してください。revision 3の測定値は旧構築の履歴であり、revision 4の測定結果として扱いません。

## 常設の環境デッキ戦

ホームの「イベント戦」から、自分の所持するデッキで32種類の構築に挑戦できます。六源それぞれの速攻・守備構築12種類、第三弾による継承構築8種類、第四弾の四系統それぞれの構築8種類、レガリアなどの混成構築4種類です。対戦相手はすべて覇王CPUです。この一覧は現有カードから作成した対戦用の構築群であり、実プレイヤーの使用率から算出したランキングではありません。

系統の絞り込み、相手の採用カードの確認、一覧のページ送り、中断・再開、撃破済み表示、直近200戦の結果保存に対応します。イベントの進行はクラウド保存・端末連携に含まれ、ソロの章進行とは独立しています。通常のCPU戦と同じ報酬計算を使用し、同一対戦の結果を再表示しても報酬を重ねて付与しません。運営から配信される期間限定のお知らせ・報酬イベントは、従来の受取ボックスから確認できます。

運営専用レガリアは、運営認証と専用デッキの利用権を確認すると、正面を向いて飛ぶ背景透過の専用イラストへ自動で切り替わります。イラストの選択・アップロード操作は不要です。専用画像は非公開のWorkerビルドにだけ組み込み、通常のカード素材・GitHub公開ファイル・セーブデータには含めません。一般プレイヤーや公開図鑑は通常イラストを表示し、カード枠・性能・GGR演出は維持します。

非公開のSitesソースでは `server/private/operator-regalia.webp` をビルド時に自動で取り込みます。明示的なビルド入力は `BEAST_KING_OPERATOR_ART_FILE` で指定できます。公開リポジトリとCIには画像を置かず、画像のない検証ビルドは安全な既存SVGを使います。画像が指定されているのに形式・サイズが不正な場合はビルドを停止します。
