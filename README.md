# ビーストキング｜BEAST KING

全1,024枚のカードから32枚以上のデッキを組み、CPUと戦うオリジナルブラウザカードゲームです。PC・スマートフォン・タブレットの画面幅に対応しています。

**公開先:** https://uni-tadayasu.github.io/beast-king/

## 収録内容

| 種類 | 枚数 |
| --- | ---: |
| 魔獣 | 512 |
| ミラクル | 256 |
| ギミック | 256 |
| 合計 | 1,024 |

星光・蒼海・紅炎・風嵐・翠樹・地晶・宵闇・霊機の8属性を収録。全カードを最初から使用できます。カード一覧、検索・絞り込み、デッキ編集、8種類のスターターデッキ、3段階のCPU対戦に対応しています。全8種類のスターターデッキは、魔獣16枚・ミラクル8枚・ギミック8枚の合計32枚で構成しています。

イラストは、魔獣16種類・ミラクル4種類・ギミック4種類の計24種類の基本モチーフを、カードのシリーズ別に共用しています。

レアリティは、**ノーマル → レア → キラレア → キラキラレア → ギラレア → ギラギラレア** の6段階です。ギラギラレアが最高位です。

## 基本ルール

- デッキは32枚以上、同じカードは3枚まで。
- コアは30から開始。相手のコアを0にすると勝利します。
- 自分のターン開始時に最大エーテルが1ずつ増え、最大値まで回復します。上限は10です。
- 魔獣は4体、ギミックは2枚まで場に出せます。
- 初期手札は4枚。手札の上限も4枚で、自分のターン開始時に4枚になるまで補充します。カード効果によるドローも4枚で止まり、上限により引けないカードは山札に残ります。
- 通常の魔獣は召喚した次の自分のターンから、1ターンに1回攻撃できます。「速攻」は召喚したターンから攻撃可能です。
- 「守護」を持つ敵の魔獣がいる場合、攻撃では守護を先に狙います。
- 魔獣同士の戦闘ダメージは同時に発生します。
- ミラクルは即時発動。ギミックは設置後、条件を満たすと自動発動します。次の自分のターン開始時に結界を付与するものや、コアを回復するものもあります。
- 山札が空の状態でドローすると、回数に応じて増える疲労ダメージを受けます。

ゲーム紹介と詳細ルールは `about.html` にも掲載しています。

## 保存と対戦

デッキや設定は、現在使用している端末・ブラウザ・サイトのローカルストレージに保存されます。ブラウザのサイトデータを消去すると保存内容も削除されます。別の端末・ブラウザ・公開URLへの自動同期はありません。

現在の対戦はCPUとの1人用です。オンライン対人戦は未実装です。

## ローカルで動かす

外部JavaScriptライブラリやビルド処理は不要です。Python 3が利用できる環境では、リポジトリのルートで次を実行します。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。ES Modulesを利用しているため、HTMLファイルの直接ダブルクリックではなくHTTPサーバー経由で実行します。

## 検証

Node.js 24を使用します。依存パッケージのインストールは不要です。

```sh
npm test
```

カード枚数・ID・名前・効果の整合性、デッキ制約、戦闘処理、カード効果、CPU対戦の進行を検証します。

## GitHub Pagesへの自動公開

このリポジトリは、GitHub Pagesの既存設定 **main /（root）** で公開します。`main` に更新を反映すると、GitHub Pagesの標準ビルド・公開処理が自動で実行されます。ゲームのHTML・JavaScript・画像はリポジトリのルートに配置しています。

`.github/workflows/check.yml` は `main` へのpushとプルリクエストで、カードデータ・対戦処理のテストと `app.js` の構文チェックを行います。公開処理はGitHub Pagesの標準機能が担当します。

公開先を変更する場合は、次のコマンドで新しいURLを指定してください。

```sh
node scripts/configure-seo.mjs https://uni-tadayasu.github.io/beast-king/
```

このスクリプトは `index.html` と `about.html` のcanonical・OGP・Twitter Card・構造化データのURLを更新し、`sitemap.xml` と `robots.txt` を生成します。リポジトリ名を含むサブパスと独自ドメインのどちらにも対応しています。SNS共有画像は `assets/social-ogp.jpg`（1,200 × 630）です。
