# レガリア・プレミアムデッキ — 運営構築改訂4

2026年11月24日。公開対象リビジョン `20261124-29` で、運営用レシピを王冠竜レガリアと専用カードだけの「プレミアムデッキ」へ更新しました。既存デッキID `operator-kirahara-v1` を維持し、`revision` は4です。一般向け構築例 `regalia-premium-v1` と構成カード・枚数は共通です。

この文書は実装と検証を記録し、本番への反映完了を表すものではありません。最新の公開対象・配信状態は [RELEASE-2026-11-24.md](RELEASE-2026-11-24.md) と最終の公開記録で確認します。

## 構築の目的とカード性能

王冠竜レガリア本体2枚を中心に、サーチ、召喚コスト軽減、手札・山札・お墓からの展開、守護・結界、回復、攻守強化、全体除去、専用合成を組み合わせます。レガリア以外の17種類は、この構築のための専用カードです。

B0512「王冠竜 レガリア」は、コスト8、攻撃力2,400、守備力2,600、守護・速攻・吸収。召喚時に相手の魔獣すべての守備力へ1,000ダメージを与え、自分のハートポイントを1,500回復します。回復上限は5,000です。この強化は公開カード定義に適用されています。

通常32枚・特殊4枚、同名2枚までの共通ルールを守ります。能力値、効果処理、CPUの判断、シャッフル、勝敗処理は全プレイヤー共通です。一般プレイヤーもカードを入手すれば同じ構築を使用できます。運営は認証済みの完成構築付与を受けられ、専用レガリア画像の利用権は別に確認します。

## 運営構築の更新

運営の完成構築付与は認証済みの運営アカウントを対象に、改訂4の受取記録 `operator-kirahara-deck-v4` で管理します。旧改訂の受取記録を確認したうえで不足枚数だけを補充し、同じ改訂を繰り返し受け取ってカードや秘宝を増やす処理にはしません。

デッキID `operator-kirahara-v1` を引き継ぎます。旧改訂の構築を更新する際、保存枠に空きがあれば旧構築を通常の保存枠へ残してから改訂4へ更新します。公開構築例は所有権を付与しないため、一般プレイヤーの編成では所持枚数を確認します。
