# 𠮷良原デッキ — 構築改訂3

2026年11月24日。第一弾から第四弾の公開カードを使う運営専用プリセットを改訂しました。デッキIDは `operator-kirahara-v1` を維持し、レシピの `revision` を3に更新しています。

## 構築の目的

王冠竜レガリア2枚を切り札として、序盤の低コスト守護と回復で場を整えます。継承強化と単体強化で守備力の高い相手を突破し、お墓の魔獣を合成素材として星巡の合成魔獣につなぎます。盤面の膠着を減らすため、敵魔獣を対象にできる除去ミラクルも採用しています。

通常32枚、特殊4枚、同名2枚までの共通ルールを守っています。能力値、戦闘ルール、CPUの判断、シャッフル、勝敗処理への運営向け補正は加えていません。全対戦で勝つことや、人間との対戦で同じ勝率になることを保証する構築ではありません。

専用プリセットの解放・自動更新は認証済み運営アカウントだけが対象です。構成カードは通常の収録カードであり、一般プレイヤーも入手したカードで構築できます。専用レガリア画像の権利・配信経路は従来どおり別管理です。

## 最終測定

構築を固定してから、探索に使っていない2つのシードを測定しました。相手は既存16構築とイベント32構築、計48構築です。各相手に対して各シード群16回ずつ、先手・後手を入れ替え、1構築につき64試合、合計3,072試合を実行しています。両側とも本番の `hard` CPUです。

| 構築 | 勝ち | 負け | 引き分け | 200ターン未決着 | 全試合に対する勝率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 旧改訂2 | 2,003 | 1,066 | 0 | 3 | 65.20% |
| 新改訂3 | 2,795 | 261 | 0 | 16 | 90.98% |

同じ48構築・同じ最終シードで約25.78ポイント改善しました。未決着を勝ちや引き分けに加えていません。新改訂3の先手は1,536試合中1,411勝、後手は1,536試合中1,384勝です。

最も苦手だった相手は「星巡の創世」で64試合中37勝でした。全対面の勝利を保証する状態には達していません。100戦100勝の目標を達成済みとは扱わず、実測した90.98%を報告します。

レガリアは1,203試合で召喚され、778試合で少なくとも1回攻撃しています。合計召喚回数は1,477回、合計攻撃回数は2,542回です。自動対戦は盤面に応じて合成や早期決着も選ぶため、すべての試合でレガリアが登場するわけではありません。

詳細な対面別結果、各シード群、レシピ、ソースハッシュは次の記録にあります。

- `operator-deck-benchmark-v3.json`: 最終構築の3,072試合。
- `operator-deck-benchmark-v2-baseline.json`: 同条件での旧構築3,072試合。
- `operator-deck-benchmark-v3-development.json`: 最終測定と区別した探索・改善の記録。

公開準備でimport/cache識別子を `20261124-27` から `20261124-28` に更新しました。最終比較の2つのJSONでは、測定当時の値を `hashes` と `measuredHashes` に保持し、公開ソースの値を `releaseHashes` に追加しています。対象9ファイルのうち5ファイルは `?v=` の識別子だけが変わり、残り4ファイルは完全一致です。識別子を戻したバイト列が測定時ハッシュと一致することを確認しており、カード・戦闘ルール・CPU・構築・試合結果は同一です。この更新で測定をやり直したとは扱っていません。開発履歴のハッシュは当時のまま保持しています。

## 探索と検証の分離

最初の候補はシード `0x6e31a5d7` の1,536試合で1,369勝、未決着18試合でした。この結果を見て追加改善したため、このシードは以後「開発用」としました。追加探索は約270秒、48構築・各8回・先後交替の768試合で候補を評価し、勝率と未決着率を優先しました。

最終のシード `0x43c97f1b` と `0x9d02e6a1` は追加探索の開始時に先に固定し、その結果を見て構築を選び直していません。数値の良いシードだけを採用していません。

イベント担当による「夜種吸収」の膠着対策が追加探索中に完了したため、追加探索が読み込んだ相手一覧と最終検証の一覧はその1構築だけ異なります。最終の新旧比較は、同じ確定版 `event-decks.js` を使用しています。

再実行例（各コマンド1,536試合）:

```sh
node scripts/operator-deck-benchmark.mjs --seeds=16 --seed=0x43c97f1b --output=/tmp/operator-v3-a.json
node scripts/operator-deck-benchmark.mjs --seeds=16 --seed=0x9d02e6a1 --output=/tmp/operator-v3-b.json
node scripts/operator-deck-benchmark.mjs --deck=docs/operator-deck-benchmark-v2-baseline.json --seeds=16 --seed=0x43c97f1b --output=/tmp/operator-v2-a.json
node scripts/operator-deck-benchmark.mjs --deck=docs/operator-deck-benchmark-v2-baseline.json --seeds=16 --seed=0x9d02e6a1 --output=/tmp/operator-v2-b.json
```

`scripts/optimize-operator-deck.mjs` はローカル専用の探索器です。ゲームやプレイヤーのセーブを変更しません。探索の成績を最終検証の成績として表示しません。
