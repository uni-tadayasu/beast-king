# 環境デッキ戦

ホームの「イベント戦」から、全4弾の収録カードを使った32種類のCPU構築に挑戦できます。ここでの環境デッキは、実際の使用率ランキングではなく、現在のカードプールから用意した対戦用の構築です。

| 系統 | 構築数 | 内容 |
| --- | ---: | --- |
| 六源 | 12 | 山・川・種・草・花・木それぞれの展開型と守備型 |
| 継承 | 8 | 星冠・蒼海・紅炎・風嵐・翠樹・地晶・宵闇・霊機を第三弾で支援 |
| 星界 | 8 | 星巡・残響・命誓・封機それぞれの展開型と守備型 |
| 混成 | 4 | 王冠竜の覇道、六源速攻連鎖、異源合成連盟、継承守護連盟 |

全構築は通常32枚・特殊4枚、同名カード2枚までの通常ルールで、CPUの強さは「覇王」です。通常版レガリアを含む対戦相手も存在します。運営専用のデッキ枠や専用イラストの権利は配布しません。

## プレイと保存

- 自分が所持しているカードで作った使用中のデッキを持ち込みます。開始時に所持枚数を確認します。
- 一覧は論理画面の高さに合わせて2件・4件・6件ずつ表示し、「六源」「継承」「星界」「混成」で絞り込めます。高さ540px以下では「対戦相手」と「対戦準備」を切り替え、選択すると準備画面へ移ります。対戦相手の全カードは低い画面では4種類、それ以外では8種類ずつのページ送りで確認できます。
- 途中の対戦は従来のCPU対戦保存枠を使います。イベント一覧またはホームから再開できます。新しいCPU対戦を始めると、その保存枠は新しい対戦になります。
- 勝利した構築を記録し、直近200試合の勝敗を保存します。敗北・引き分け・投了では撃破扱いになりません。同じ対戦の結果は繰り返し記録しません。
- 対戦報酬は既存のCPU対戦報酬を使用し、イベント独自のカード授与や二重報酬はありません。
- ソロの章の進行とは独立しています。イベント進行とイベント対戦の識別情報は、バックアップ・クラウド保存に含まれます。
- 運営が配信する期限付きのお知らせ・プレゼントは、右上の「開催中のお知らせ」から確認できます。この常設CPU一覧とは別に、既存の配信管理に従います。

## 検証

`tests/event-battles.test.mjs` は32構築の合法性・重複・全系統の網羅、通常エンジンによる先後両方64試合の完了、結果の重複排除・保存件数の上限、全ページから全相手へ到達できることと通常イラストの使用を検証します。

`tests/app-integration.test.mjs` は本番アプリの実経路で、イベント開始・所持カード不変・運営権利不変・保存復元・再開・結果の一度きりの処理・再戦導線・不正な保存識別情報の拒否を検証します。クラウド側の保存契約は `tests/account.test.mjs` で検証します。

強さの数値を表示する際は、対戦相手・先後・乱数・CPUの操作条件を付記してください。構築の数は可能な組み合わせの総数ではありません。
