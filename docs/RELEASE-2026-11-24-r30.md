# r30 — Cyber interface and deck management

## User-visible changes

- Dark navy panels, cyan controls and clearer sans-serif type across the main game. The short-screen editor keeps names and quantities next to the illustrations instead of shrinking the whole interface.
- Card details show the complete effect in readable pages on phones; card information and recipe return links remain available.
- Short synthesized cyber sounds distinguish selection, navigation, confirmation, cancellation and denied actions. Sound settings include volume and a preview; disabled controls and hover do not play sounds. Existing music and battle sounds remain intact.
- Deck settings include a named confirmation before deleting a saved deck and its draft. Owned cards, treasure, results and paused games are retained. Deleting the active deck selects another usable saved deck; the last usable deck is protected.
- Deleted starter deck IDs are validated and synchronized so deleted presets do not reappear. Explicitly loading a starter restores that deck without granting extra cards.
- Cloud sync compares content fingerprints before declaring changes. Unchanged saves and equivalent newer revisions no longer create false conflicts. Real conflicts keep an explicit data choice; the premium-deck action opens that choice when needed.
